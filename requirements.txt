# All versions below are pinned to exact, locally-verified-working releases.
# Streamlit Cloud installs with `uv pip install` and no lock file, so any
# unpinned package here can silently resolve to a newer, incompatible release
# on redeploy and crash the app in production while it keeps working locally.
# This has already happened twice (mcp, then streamlit/starlette) — when
# bumping a version on purpose, verify `./run.sh app` still starts cleanly
# before pushing, and update the pin here rather than removing it.
